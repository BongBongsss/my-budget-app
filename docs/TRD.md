# TRD

- 프로젝트 루트 `AGENTS.md`에 작업 지침을 두고 `docs/`의 네 문서에 작업 상태를 기록한다. (§D1)
- 규칙 문서 수정 예외의 대상은 Codex 지침 파일 `AGENTS.md`다. (§D2)

- 공통 작업 지침은 `AGENTS.md`를 기준으로 하며 도구별 진입 문서에서 이를 안내한다. 통합 전 지침 원문은 `_archive/instructions/`에 보관하고 현행 정책으로 적용하지 않는다. (§D3)
- 문서화 적용 범위와 지침 단독 수정 예외를 명확히 하고, 위험 기반 테스트·푸시 전 검증·DB 운영 문서 참조를 공통 지침에 반영한다. (§D4)
- 검증 비대상과 미검증 상태를 구분하고, 푸시 날짜 정정·검증 불가 대응·기존 문서 확인·병렬 작업 기록 충돌 처리 기준을 둔다. (§D5)
- 제품 요구사항의 기준 문서는 루트 `BudgetSpec.md`이며 `server/BudgetSpec.md`에서 이를 안내한다. 과거 인수인계·리뷰 문서는 `_archive/history/`에 보관한다. (§D7)
- 문서별 역할은 `docs/README.md`에서 안내한다. 중복 메모의 기준은 루트 `나중에 할일.txt`이며 서버 쪽은 안내로 유지한다. (§D8)
