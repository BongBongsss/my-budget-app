# PRD

- 프로젝트 작업에는 문서화 절차를 적용한다. (§D1)
- 고정지출은 승인된 월별 거래와 비교해 자동 또는 사용자 확인으로 매칭하고, 미매칭 상태를 표시한다. 새로운 거래는 사용자가 직접 반영할 때만 생성한다. 상세 요구사항은 `BudgetSpec.md`를 참고한다. (§D6)

- 월간·연간 리포트는 요약, 미승인 경고와 구성원별 카테고리·거래처 탐색을 제공한다. Make를 이용해 두 수신자에게 동일한 월간 리포트를 발송하도록 준비한다. (진행중 — LOG D61; §D28, §D14)
- 명시적으로 활성화한 로컬 개발 환경에서는 비밀번호 입력 없이 관리자 접속을 제공한다. 운영 인증은 유지한다. (§D16)
- 비교용 시안을 제거하고 선택된 시안 3을 리포트 탭으로 통합했다. (§D28, §D27)
- 리포트 탭에 기간 이동·카테고리 증감·월별 수입·지출 및 카테고리 추세·증감 원인·소비 패턴·구성원 비교를 제공한다. (§D35, §D30)
- 리포트는 선택 카테고리 요약과 6개월 추이를 상단에 표시하고 오른쪽에서 거래처 상세를 보여준다. 월별 그래프에는 수입 − 지출 차액을 부호와 함께 표시한다. (§D35, §D31, §D34)
- 각 관리 탭의 본문은 리포트와 동일한 최대 너비로 가운데 정렬한다. (§D38)
- 리포트의 가운데 기간 표시를 눌러 연도와 월을 선택한다. 연간 모드에서는 연도만 선택하고, 선택 즉시 적용하며 선택창 바깥을 누르면 닫는다. (§D45, §D50)
- 로컬에서 검토한 리포트 및 화면 변경을 필수 검증 후 운영에 반영했다. (§D54)
- 모바일 메뉴는 선택한 탭의 이름과 나머지 탭의 아이콘을 표시한다. 리포트에서는 제목 옆에 필터를 두고 미승인 건수를 안내하며, 카테고리를 누르면 거래처를 하나씩 펼치거나 접는다. (§D60)
- 월간 메일은 미승인 경고, 수입·지출·차액, 전월 변화, 주요 카테고리, 자료가 충분한 경우의 평균 비교, 구성원 요약과 최근 3개월 추세를 담는다. 실제 발송은 시험 확인 후 연결한다. (진행중 — LOG D61)
