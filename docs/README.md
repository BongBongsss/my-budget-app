# 프로젝트 문서 안내

- [PRD.md](./PRD.md): 확인된 제품 요구사항과 변경 사항. 기존 제품 요구사항은 루트의 [BudgetSpec.md](../BudgetSpec.md)도 참고한다.
- [TRD.md](./TRD.md): 현재 문서·설계·운영 기준.
- [PLAN.md](./PLAN.md): 작업 마일스톤과 상태.
- [LOG.md](./LOG.md): 프로젝트 작업 이력과 검증 결과.
- [CHANGELOG.md](../CHANGELOG.md): 앱 버전과 소스·배포 상태에 관한 이력. 작업 이력과 목적이 다르므로 각각 유지한다.
- [VERIFY_BEFORE_PUSH.md](../VERIFY_BEFORE_PUSH.md): 푸시 전 검증 절차.
- [VERIFICATION_SCENARIOS_2026-06-05.md](../VERIFICATION_SCENARIOS_2026-06-05.md): 과거 검증 시나리오. 운영 기준 문서에서 참조하므로 기존 위치를 유지하며, 기록된 데이터 수치와 현재 동작은 사용 전에 확인한다.
- [_archive](../_archive/README.md): 과거 지침과 인수인계·리뷰 자료.

기존 문서의 최신성은 개별적으로 확인해야 하며, 실제 구현이나 사용자의 확정된 요구사항과 차이가 있으면 근거를 확인한다.
