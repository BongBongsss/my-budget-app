# 2026-08-11 Fixed Cost Management Update

## Summary

Today’s work expanded fixed-cost management, improved the related UI, and
fixed recurring-candidate matching for statement descriptions that contain
changing suffixes.

## Delivered Changes

### Fixed-cost management

- Added a dedicated fixed-cost manager for expense items, including registered
  items, recommendation candidates, and excluded recommendations.
- Added member filtering, category/group composition, and responsive desktop
  and mobile layouts.
- Added a missing-transaction workflow so a fixed-cost item expected in a
  month can be added to the transaction list with its actual amount.
- Added controls to add, edit, activate/deactivate, defer, ignore, and restore
  fixed-cost recommendations.
- Added card-level memo display and improved the readability of fixed-cost
  cards, controls, navigation, and filter chips.

### Recommendation matching

- Normalized changing reference-number suffixes before grouping transactions
  into a fixed-cost candidate. The same normalized key is used for candidate
  grouping, existing-item exclusion, defer, and ignore actions.
- Preserved numeric-only transaction descriptions. For example,
  `15191035272707` now remains a usable candidate key rather than being
  mistaken for a trailing reference number.
- Normalized month-and-reference forms such as `새마을07-030` and
  `새마을06-029` to the shared label `새마을`, allowing those monthly
  transactions to form one candidate.
- Added automated coverage for numeric-only descriptions, month/reference
  suffixes, and named merchants with trailing reference numbers.
