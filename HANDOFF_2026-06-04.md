## Important Gotchas

한국어 설명: 다음에 이어서 작업할 때 실수하기 쉬운 부분입니다. 특히 운영 Neon에 위험한 명령을 치면 안 됩니다.

- Do not use `npm run dev` in `server` unless network access for `npx -y node@20` is available.
- 한국어: 서버는 일반 `npm run dev` 대신 아래 명령을 쓰는 것이 안전합니다. 일반 dev 스크립트는 `node@20`을 네트워크에서 받으려다 멈출 수 있습니다.
- Use this for local backend:

```powershell
cd server
npm run dev:system-node
```

- Use this for local frontend:
- 한국어: 프론트는 아래 명령으로 띄웁니다. 주소는 `http://127.0.0.1:3000`입니다.

```powershell
cd client
npm run dev -- --host 127.0.0.1
```

- If `psql` appears to hang, it is probably waiting for a password prompt.
- 한국어: `psql`이 멈춘 것처럼 보이면 대부분 비밀번호 입력을 기다리는 중입니다.
- Use:

```powershell
$env:PGPASSWORD='postgres'
```

- Add `-w` to `psql`, `createdb`, or `pg_restore` commands.

- Do not run destructive production DB commands:
  - 한국어: 운영 Neon DB에는 데이터 삭제/초기화 명령을 절대 바로 치지 않습니다.
  - Do not run `db push --force-reset` against Neon.
  - Do not restore local DB dumps into Neon unless explicitly intending to overwrite production data.
  - Do not drop production tables.
