# 과거 자료 보관소

이곳의 자료는 이력과 참고를 위해 보존하며 현행 지침으로 적용하지 않는다.
현재 공통 지침은 [AGENTS.md](../AGENTS.md), 작업 이력은 [docs/LOG.md](../docs/LOG.md)를 따른다.
전체 문서의 용도는 [docs/README.md](../docs/README.md)를 참고한다.

- `instructions/`: 통합 전 도구별 지침 원문과 개정 이력.
- `history/`: 과거 인수인계 문서와 2026-08-05 코드 리뷰 기록.
- 자료를 보관하기 전 현재 사용 여부와 참조를 확인하고, 이동 시 관련 링크를 정리한다.
- 백업·데이터·운영 문서는 오래되었다는 이유만으로 옮기거나 삭제하지 않는다.
